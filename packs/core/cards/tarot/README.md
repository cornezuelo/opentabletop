# The tarot's pictures

The 78 cards of the Rider–Waite–Smith tarot as published in 1909 (drawn by Pamela Colman Smith, who died in 1951): in the public domain. Taken from the scans on Wikimedia Commons (`RWS Tarot 00 Fool.jpg` … `RWS Tarot 21 World.jpg`, `Wands01.jpg` … `Pents14.jpg`), marked _Public domain_ there, shrunk to 240 px wide and kept as WebP. Each file is named by the card's id in `cards.yaml`.
