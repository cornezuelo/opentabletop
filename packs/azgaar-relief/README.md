# Azgaar's relief icons

Relief icons from [Azgaar's Fantasy Map Generator](https://github.com/Azgaar/Fantasy-Map-Generator) (`src/assets/icons/relief`, commit `83838f14`), for OpenTabletop's map styles to draw terrains with (`art.terrains.<terrain>.images`). Two of its sets:

- `colored/`: flat colours (Core's **Relief** style);
- `illustrated/`: drawn in earth tones (the Grey Marches' **Engraved atlas** style). Its lines take their colour from the generator's CSS, which an image doesn't have, so each file has it on its root (`stroke="#5a4630"`); otherwise unchanged.

Each has the same 34 pictures: `mount-1`…`mount-6`, `mountSnow-1`…`mountSnow-6`, `hill-1`…`hill-4`, `conifer-1`, `coniferSnow-1`, `deciduous-1`, `deciduous-2`, `acacia-1`, `palm-1`, `deadTree-1`, `deadTree-2`, `cactus-1`…`cactus-3`, `dune-1`, `grass-1`, `swamp-1`, `swamp-2`, `vulcan-1`…`vulcan-3`.
