# What tables see

Every roll gets a **context**: values a table can use in its dice (`{{place.danger}}`), its texts and its conditions (`when: { place.danger: { gte: 2 } }`). This page is the reference of every value: its name, what kind of value it is, the values it can take, and where they come from (and where to see them in the apps). At the end: which one wins when two have the same name.

## How to read this page

Each value has a **full name** that says where it comes from (`place.terrain`) and most a **short name** too (`terrain`). Both read the same value: `terrain: forest` and `place.terrain: forest` hold in the same cells, and `{{season}}` writes the same as `{{time.season}}`.

| Full names           | What they are about                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `place.*`            | [the place](#the-place-place): its id, terrain, tags, region, icon and its own values          |
| `time.*`             | [the moment](#the-moment-time): season, day, hour, the parts of the day and the calendar       |
| `system.*`           | [the system's own day](#the-system-s-day-system), as numbers                                   |
| `trip.*`             | [the trip](#the-trip-trip): its day, way of travelling, weather, what it has done              |
| `world.*`            | [the world clock](#the-world-world-and-factions) (a campaign's)                                |
| `party.*`            | [the party](#the-party-party): its stats, its sheet, its items and characters                  |
| `present.*`          | [those present](#those-present-present): copies of the system's templates where the party is   |
| `today.*`            | [the values of the day](#the-day-s-values-today-yesterday), and `yesterday.*` the day before's |
| `from.*`, `around.*` | [the cell left and the cells around](#around-the-party-from-around)                            |

- **Short names** are quicker to write, and are what you type in the Oracle's **Context** box: `terrain: forest` there fills `place.terrain` too.
- **Full names** can't be hidden: a party stat, a value of the day or a binding's context called `weather` or `day` takes the short name (see [Which value wins](#which-value-wins)), never the full one. The Grey Marches' travel rules and the Generic rules use them.

**Kinds of value** in the tables below: a **number** (`3`, `14.5`: adds up in dice, compares with `gt` / `gte` / `lt` / `lte`), **yes/no** (`true` / `false`), **text**, an **id** (a text the system or the map declares: `forest`, `market-day`), a **list** (several ids at once: a condition holds if the list has the one asked for, `place.tags: landmark`) or a **group** (names inside: `place.icon.guards`). A value that isn't there reads as **0** in dice and **doesn't match** in conditions (except `exists: false` or `not`): see [Conditions](08-conditions.md).

**Where** says which apps give it: **Map** (a map: the selected cell, or the party's on a trip), **Travel** (a trip without a map: a line of cells, each with a terrain, tags and roads to the next), **trip** (a trip in either), **hand rolls** (the Oracle panel or app).

## The place, `place.*`

Where the party is (today always a cell): the selected cell, the party's on a trip, or the cell a check is about (the one entered, the one where an action is taken).

| Full name                                       | Short     | Kind                   | Values, and where they come from                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------- | --------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `place.id`                                      | —         | id                     | The cell's key: column and row counted from 0 (`"4,2"`), whatever the map's coordinate labels (`0503`). Shown beside the coordinates in the cell's panel. In Travel, its place on the way (`"0"`, `"1"`…); arriving through a way into another map (a [sub-map](../map/13-sub-maps.md)), that map's place, `"@barrowhalls1/area:barrowstair1"` (a room there, or a cell, `"@oldmine1/0,3"`), until the trip goes on there.                          |
| `place.terrain`                                 | `terrain` | id                     | The terrain's id (`forest`, `dense-forest`, `lake`…), never its name, in any language. The map's palette decides which exist: **Edit palette** shows each id, and the cell's panel the cell's. Missing on a blank cell.                                                                                                                                                                                                                             |
| `place.water`                                   | `water`   | yes/no                 | `true` when the terrain is marked **Water** in the palette (Travel: `lake`, `sea`, `deep-sea`). `false` otherwise.                                                                                                                                                                                                                                                                                                                                  |
| `place.floor`                                   | `floor`   | yes/no                 | `true` when the terrain is marked **Floor** in the palette (a room's, a corridor's). Map only.                                                                                                                                                                                                                                                                                                                                                      |
| `place.tags`                                    | `tags`    | list of texts          | The cell's tags (`landmark`, `ford`, `shrine`…): whatever you write in the cell's **Tags** (it suggests those used on the map). Empty list when it has none.                                                                                                                                                                                                                                                                                        |
| `place.region`                                  | `region`  | text or list           | The region's **name** as written (`Ashford Vale`), not its id. In a region [inside others](../map/03-regions.md#regions-inside-regions), the list of them all, innermost first: a condition holds for any (`place.region: The Greywood` in its Deepwood too). Map only. The **Regions** tool lists them.                                                                                                                                            |
| `place.<value>`                                 | `<value>` | number, yes/no or text | Each value of the cell's **regions**, from the outermost in, then the **cell's own** (the innermost wins on the same name, and the cell over all): `danger`, `elevation`… Typed as `3` it's a number, `true` / `false` yes/no, anything else text. The cell's panel lists its own and, below, those it gets from its region. Map only.                                                                                                              |
| `place.name`                                    | `name`    | text                   | The cell's name, when it has one. Map only.                                                                                                                                                                                                                                                                                                                                                                                                         |
| `place.icon`                                    | `icon`    | group                  | The cell's icon: `icon.id`, its id (`game:castle`; imported images `asset:<id>`: shown under the Icons tool's palette, in its tooltips and in the cell's panel), and each of its values by name (`icon.guards`), kinds as above. Missing when the cell has no icon. Map only.                                                                                                                                                                       |
| `place.faction`                                 | —         | id                     | The id of the faction that holds the cell (`iron-clans`), with factions on the map. Map only.                                                                                                                                                                                                                                                                                                                                                       |
| `place.pois`                                    | —         | list of ids            | The ids of the places (POIs) in the cell: what characters' relations point at (`poi:<id>`). Map only.                                                                                                                                                                                                                                                                                                                                               |
| `place.related`, `place.relations.<kind>`       | —         | list of ids            | The characters tied to the cell, it, its region or a place in it, as their relations say (`place.related: mara`); by kind of relation (`place.relations.home: mara`). See [Characters](#characters).                                                                                                                                                                                                                                                |
| `place.connections`, `place.connections.<kind>` | —         | group                  | The connections leaving the place, by kind: those drawn with Map's **Connections** and the roads and rivers through it. `place.connections: door` holds where one leaves it; `place.connections.door` is that kind's id, name, tags, values and state in this trip (`place.connections.door.state: locked`). Several of a kind together: a value they share as it is, values that differ as a list. In Travel, the legs before and after the place. |

A **room** (a region played as one place, [Rooms](../map/03-regions.md#rooms)) is one place: `place.name` is the region's name, `place.tags` every tag of its cells, `place.terrain` their most common terrain, its values the region's; its id is `area:<the region's id>`.

Examples: `when: { place.terrain: [forest, dense-forest] }` (either), `when: { place.tags: ford }`, `when: { place.danger: { gte: 3 } }`, `when: { place.icon.id: game:castle }`, `'1d6 + {{icon.guards}}'`, `when: { place.region: Ashford Vale }`.

Points of interest keep their values in the map and its file, but tables don't read them: a cell can have several.

**The selected token** (hand rolls from Map's Oracle panel), `token.*`:

| Name                              | Kind         | Values, and where they come from                                                                                                                   |
| --------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `token.name`                      | text         | Its name.                                                                                                                                          |
| `token.kind`                      | id           | `pc`, `npc`, `enemy` or `party` (its panel's **Kind**).                                                                                            |
| `token.<value>`                   | as `place.*` | Each value written in its panel (`token.fare`).                                                                                                    |
| `token.values.<id>`, `token.<id>` | number       | With a **sheet** (Give it a sheet): each value of the sheet (`token.values.health`, also `token.health`); ids as the system's sheet declares them. |
| `token.conditions`, `token.tags`  | list of ids  | Its sheet's conditions it has now (`token.conditions: wounded`), and its tags.                                                                     |
| `token.relations.<kind>`          | list         | Its relations by kind, as a character's.                                                                                                           |

## The moment, `time.*`

On a trip, and in hand rolls while a trip or the world clock runs.

| Full name         | Short        | Kind          | Values, and where they come from                                                                                                                                                                                                                                                                                             |
| ----------------- | ------------ | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `time.season`     | `season`     | id            | `spring`, `summer`, `autumn`, `winter`; with a calendar of the system's own, the seasons its months name (Systems → **Calendar**).                                                                                                                                                                                           |
| `time.day`        | `day`        | number        | The day number since the calendar's start (1, 2…).                                                                                                                                                                                                                                                                           |
| `time.hour`       | `hour`       | number        | The hour with minutes as a fraction: `14.5` is 14:30, `0` midnight, up to `23.98…`. `time.hour: { gte: 18 }`: from six in the evening.                                                                                                                                                                                       |
| `time.watch`      | `watch`      | number or id  | The watch of the day, when the calendar has a `watch` division: 1 to the number of watches for `every` (the default calendar: six of four hours, 1 from midnight to 4:00), or the id of its part for watches of their own (`time.watch: middle`); absent in a gap.                                                           |
| `time.<division>` | `<division>` | id or number  | With divisions of the day in the calendar: the part it is now in each, by the division's id (`time.meal: elevenses`; a numbered one's number, `time.bell: 3`); absent in a gap. Its short name only when it isn't another fact's (a division `region` is only `time.region`). Systems → **Calendar** → Divisions of the day. |
| `time.tags`       | —            | list of words | The tags of every part it is now (`time.tags: dark`); empty without divisions.                                                                                                                                                                                                                                               |
| `time.month`      | `month`      | id            | With a calendar of the system's own: the month's id (Systems → **Calendar**: each month's id).                                                                                                                                                                                                                               |
| `time.monthDay`   | `monthDay`   | number        | With a calendar of the system's own: the day of the month, from 1.                                                                                                                                                                                                                                                           |
| `time.year`       | `year`       | number        | With a calendar of the system's own: the year.                                                                                                                                                                                                                                                                               |
| `time.weekday`    | `weekday`    | id            | With a calendar that has weekdays: today's id.                                                                                                                                                                                                                                                                               |
| `time.moons.<id>` | `moons.<id>` | id            | With moons in the calendar: each moon's phase by the moon's id: `new`, `waxing`, `full` or `waning` (`time.moons.pale: full`).                                                                                                                                                                                               |
| `time.holidays`   | `holidays`   | list of ids   | With holidays in the calendar: the ids of today's (empty most days).                                                                                                                                                                                                                                                         |

## The system's day, `system.*`

Numbers from the system's own rules (Systems → **Rules**), to compare with without writing them twice: `time.hour: { gte: '{{system.part.night}}' }`.

| Full name                  | Short         | Kind   | Values                                                                                                                             |
| -------------------------- | ------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `system.hoursPerDay`       | `hoursPerDay` | number | The hours its ways of travelling's km a day are marched in (`8`): `trip.marched: { lt: '{{system.hoursPerDay}}' }` in its march.   |
| `system.<division>.<part>` | —             | number | When a part of the calendar's day starts, as an hour (`system.meal.dinner`: `18`): `time.hour: { gte: '{{system.meal.dinner}}' }`. |

## The trip, `trip.*`

On a trip (Map Play, Travel), for its checks and actions, and in hand rolls during it.

| Full name                                 | Short            | Kind          | Values, and where they come from                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------- | ---------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `trip.day`                                | `tripDay`        | number        | The day of this trip: 1 the day it started.                                                                                                                                                                                                                                                                                                                                |
| `trip.mode`                               | `mode`           | id            | The way of travelling's id (`foot`, `horse`, `boat`…): the system's ways (Systems → **Rules** → Ways of travelling); the trip's selector shows their names.                                                                                                                                                                                                                |
| `trip.weather`                            | `weather`        | id            | Today's weather once a table or weather model has set it: the ids the system's weather declares (Systems → **Rules** → Weather, or **Weather** models). Missing until then.                                                                                                                                                                                                |
| `trip.connections`                        | `connections`    | list of ids   | The kinds of connection of the stretch (roads, trails, rivers): `road`, `trail`, `river` (or the kinds the system declares), with those of the connections drawn on the map (Map's **Connections**: a `bridge`, a `tunnel`…). Entering a cell, the one just walked; otherwise the one ahead on the route (at a moment of the day, in camp, for an action). Empty off them. |
| `trip.marched`                            | `marched`        | number        | Hours marched today (`2.5`).                                                                                                                                                                                                                                                                                                                                               |
| `trip.doneToday`                          | `doneToday`      | list of ids   | The ids of the actions taken today (`trip.doneToday: forage`): the system's actions (Systems → **Rules** → Actions).                                                                                                                                                                                                                                                       |
| `trip.routeLeft`                          | `routeLeft`      | number        | Cells left to the destination (0 without a route).                                                                                                                                                                                                                                                                                                                         |
| `trip.arrived`                            | `arrived`        | yes/no        | Whether the party is at its destination.                                                                                                                                                                                                                                                                                                                                   |
| `trip.visits`                             | `visits`         | number        | Times the party has been in this cell during the trip: `1` the first time.                                                                                                                                                                                                                                                                                                 |
| `trip.moment`                             | `moment`         | id            | For a system's actions and checks: the moment that brought them: `trip.place-enter`, `time.day-end`, a clock (`06:00`), a part of the calendar's day (`time.part.morning`), an action (`actions.camp`), a clock of the world filling, `world.clocks.<id>.full`, or a world turn, `world.turn` (for an action with `on:` or a check with `at:` naming several).             |
| `trip.doing`                              | `doing`          | id            | The action under way (`camp`; at `time.day-end`, the one the day ended in). Missing when none.                                                                                                                                                                                                                                                                             |
| `trip.below`, `trip.above`                | `below`, `above` | list of names | What an effect tried to take past its `min` (`trip.below: party.values.food`) or `max` today, by full name: the party's stats, its sheet's values and items (`party.items.ration`), the characters' values (`characters.kael.values.health`).                                                                                                                              |
| `trip.places`                             | —                | number        | Cells entered during the trip.                                                                                                                                                                                                                                                                                                                                             |
| `trip.km`                                 | —                | number        | The km of those steps, each at the map's scale (Map settings), else the system's (`travel.cellKm`).                                                                                                                                                                                                                                                                        |
| `trip.hours`                              | —                | number        | Hours marched since the trip started.                                                                                                                                                                                                                                                                                                                                      |
| `trip.checks`                             | —                | number        | Checks that have come up during the trip.                                                                                                                                                                                                                                                                                                                                  |
| `trip.taken.<action>`                     | —                | number        | Times each action was taken during the trip, by the player or the system itself; every action the system declares is there, 0 until taken (`trip.taken.camp: { gte: 7 }`).                                                                                                                                                                                                 |
| `trip.spent.<name>`, `trip.gained.<name>` | —                | number        | How much the system's actions, checks and tables took from each of the party's values and items and added to it (hand edits don't count), by full name: `trip.spent.party.items.ration`, `trip.gained.party.values.food`; its own and its characters' together, every one there from 0.                                                                                    |

The trip panel's **So far** line (open it for the rest) shows these counts as they stand.

**An action's parameters, `params.*`.** An action's own conditions (`when` / `unless`), its steps and their conditions also read the parameters it was taken with: `params.until` is the choice made beside its button (or given by a `do:` step's `with:`, or by `travel.onward`), its default when nobody chose (`travel.move: '{{params.until}}'`, a step `when: { params.pace: quick }`). Only there: checks and tables don't see them. See [Actions](../oracle/07-connecting.md#5-your-own-travel-system).

## Around the party, `from.*`, `around.*`

| Name                           | Kind        | Values                                                                                                                                              |
| ------------------------------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `from.*`                       | group       | Entering a cell, the one left, with the same names as `place.*`: `from.id`, `from.terrain`, `from.tags`, `from.region`, its values, `from.related`. |
| `around.terrain`               | list of ids | Every terrain among the cells next to the party's (`around.terrain: lake`: next to a lake).                                                         |
| `around.tags`, `around.region` | list        | Every tag, and every region name, among them.                                                                                                       |
| `around.water`                 | yes/no      | Whether any of them is water.                                                                                                                       |

In Travel, a cell's neighbours are the ones before and after it on the way.

## The connection of the step, `connection.*`

The connection of the stretch the party is on (the one just crossed entering a place, else the one ahead on the route), as a terrain's or a connection's **Open when** / **Closed when**, a way of travelling's **Only through**, checks, actions and tables read it:

| Name               | Kind       | Values                                                                                                                                                                      |
| ------------------ | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `connection.kind`  | id         | Its kind: a connection drawn with Map's **Connections** (`bridge`, `door`…), else the road or river followed (`road`). Missing off them.                                    |
| `connection.id`    | id         | A drawn connection's id (missing on roads and rivers).                                                                                                                      |
| `connection.name`  | text       | A drawn connection's name, if it has one.                                                                                                                                   |
| `connection.tags`  | list       | A drawn connection's tags (`connection.tags: hidden`).                                                                                                                      |
| `connection.<key>` | as written | A drawn connection's values (`connection.dc`), and what the trip changed of them: `connection.state: open` once an effect opened it. The trip's change wins over the map's. |

In Travel, the connection to the next cell is the leg's: its first kind, with an id of its own (`leg-0`, `leg-1`…) for what the trip changes.

An effect `connection.<key>` changes the connection of the stretch in this trip, never on the map: a word sets it (`connection.state: open`), a number adds to it (`connection.uses: -1`; `'=3'` sets it). An action's step changes it at once, so its next steps see it; a table's or check's result too. The journal says it (`Oak door: state open`).

An effect `place.connections.<kind>.<key>` does the same to every connection of that kind leaving the party's place, drawn on the map (`place.connections.hidden-path.state: found`, a path found from where it starts): what a check or an action changes without crossing it.

## The party, `party.*`

| Name                             | Kind        | Values, and where they come from                                                                                                                                                                                                                   |
| -------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `party.stats.<stat>`             | number      | Each stat the system's bindings declare (Systems → **Checks** → Party stats), with its current value, as the trip panel shows them. Also by its own name, `{{charisma}}`, unless a fact has that name (see below).                                 |
| `party.items.<item>.count`       | number      | How many of an item the party has, its own sheet's and its characters' together (`party.items.ration.count: { lt: 1 }`); every item of the system's catalogues is there, 0 while nobody has one. Also `party.items.tags`, every tag of every item. |
| `party.mode`                     | id          | The way of travelling, as `trip.mode`.                                                                                                                                                                                                             |
| `party.members`                  | list of ids | The characters' ids, when the party has characters.                                                                                                                                                                                                |
| `party.values.<value>`           | number      | The party's own sheet's values (Systems → **Sheet**, the party's: `partySheet`), within its bounds, whoever travels: `party.values.morale`, or what it carries, `party.values.food`.                                                               |
| `party.conditions`, `party.tags` | list of ids | The conditions and tags of the party's own sheet: `party.conditions: shaken`.                                                                                                                                                                      |
| _each party stat_                | number      | `{{charisma}}`: the stat by its own name (the short way).                                                                                                                                                                                          |

Also in hand rolls during a trip.

## The day's values, `today.*`, `yesterday.*`

| Name                | Kind                 | Values, and where they come from                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `today.<value>`     | yes/no, number, text | The values of the day the system declares (Systems → **Rules** → Values of the day: `today.lost`, set by a table's `set`, an action's `set:` step or a check's outcome), and the weather a table set earlier today (`weather`); a declared modifier the same way (`today.fordModifier`). They clear as the day ends, at midnight. Each is also there by its own name: `lost`, `fordModifier`. The journal says when each is set. |
| `yesterday.<value>` | as `today`           | The day before's: `yesterday.lost` (the party ended it lost; `false` if not), `yesterday.weather`… E.g. finding the way again with disadvantage: `modeWhen: { roll-modes.disadvantage: { yesterday.lost: true } }`.                                                                                                                                                                                                              |

## Characters

When the system has a [sheet](07-kinds.md#sheets) and the party has characters (the trip's **Characters** section). Ids are the characters' (each card says how it's read: `characters.kael.values.health`); values and conditions are the ones the system's sheet declares (Systems → **Sheet**).

| Name                                                                         | Kind         | Values                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `party.members`                                                              | list of ids  | The characters' ids: `party.members: kael` holds while Kael travels with the party.                                                                                                                                                                  |
| `characters.<id>.values.<value>` (also `characters.<id>.<value>`)            | number       | One character's value, within the bounds the sheet gives it.                                                                                                                                                                                         |
| `characters.<id>.conditions`                                                 | list of ids  | The conditions it has now (`characters.kael.conditions: wounded`).                                                                                                                                                                                   |
| `characters.<id>.tags`, `characters.<id>.name`                               | list, text   | Its tags and its name.                                                                                                                                                                                                                               |
| `characters.<id>.relations.<kind>`, `characters.<id>.bonds.<kind>`           | list, number | Its relations by kind (`characters.mara.relations.home: region:Ashford Vale`: `region:<name>`, `hex:<id>`, `poi:<id>` or `character:<id>`) and the number each one carries.                                                                          |
| `characters.<id>.items.<item>.count`, `characters.<id>.items.<item>.<field>` | number       | How many of an item it has (all of them, by the item's id: `characters.kael.items.torch.count: { gte: 1 }`) and the first one's fields as the sheet declares them (`….items.torch.uses`). No such item: nothing there, so `{ exists: false }` holds. |
| `characters.<id>.items.tags`, `characters.<id>.items.<item>.tags`            | list         | Every tag of every item it carries (`acting.items.tags: light`), and one item's.                                                                                                                                                                     |
| `characters.<id>.places.<place>.used`, `.room`, `.items`                     | number, list | Each place (the sheet's, its own, and its containers by key): how much is taken (by **What fills a place**), its room, and the ids of the items right in it. See [Items](../systems/08-items.md).                                                    |
| `characters.<id>.carried.used`, `.room`                                      | number       | All it carries (every item, inside containers and in no place too, by **What fills a place**), and the sheet's **Room in all** (none: no `.room`). See [Limits to carrying](../systems/08-items.md#limits-to-carrying).                              |
| `roles.<role>.*`                                                             | group        | Whoever holds one of the system's journey roles (Systems → **Checks** → Journey roles), with the same names: `roles.guide.values.pathfinding: { gte: 2 }`. Nobody in it: there is no `roles.<role>`.                                                 |
| `acting.*`                                                                   | group        | The character acting now (chosen in the trip), with the same names: `acting.values.survival: { gte: 2 }`. Nobody acting: there is no `acting`, and a condition on it doesn't hold.                                                                   |
| `place.related`, `place.relations.<kind>`, `from.related`                    | list of ids  | Who is tied to the cell (it, its region or a place in it) and by which kind of relation; `from.related` for the cell left.                                                                                                                           |

Effects reach them with the same names ([Syntax](09-syntax.md#changing-the-party-effects)): `party.members.values.health: -1` (every character), `characters.kael.conditions.wounded: true` (one), `acting.values.health: 1` (the one acting; with nobody acting it changes nothing, and the journal says so), `roles.lookout.values.health: -1` (whoever holds a role), `acting.items.torch: -1` (one item fewer; `+1` gives one, from the system's catalogues when it has none), `party.members.items.torch.uses: -1` (a field of each one's first torch). A party with no characters ignores them: the same system plays with or without characters.

A value **made of others** (`from:` on the sheet) and a condition that **holds by itself** (`when:`) are read like any other, but no effect changes them: the journal says _“Kael: Wounds” holds by itself…_ and nothing changes. Inside its own sheet (a `from`, a bound, a condition's `when`), a character reads itself as `self.*`: `self.values.health`, `self.conditions`, `self.tags`; a condition's `when` reads the world too, with the names on this page ([Sheets](07-kinds.md#sheets)).

The party's stats a system makes of its characters (`from` in its bindings) are read as any other stat (`party.stats.navigation`), and the items they carry as the party's together: `party.items.ration.count`.

## Those present, `present.*`

When the system has a [bestiary](07-kinds.md#bestiaries) and a result made copies of its templates (`present.wolf: 3`): the copies at the party's place. Each copy is a character too, read by its id as the party's are (`characters.wolf-2.values.health`), with its own sheet's values and conditions.

| Name                                                 | Kind                | Values                                                                                                                    |
| ---------------------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `present.ids`                                        | list of ids         | The copies here: `present.ids: wolf-2` holds while that wolf is here.                                                     |
| `present.count`                                      | number              | How many are here, of every template.                                                                                     |
| `present.tags`                                       | list                | Every tag of those here: `present.tags: outlaw`.                                                                          |
| `present.<template>.count`, `present.<template>.ids` | number, list of ids | How many copies of one template are here, and which; every template of the system is there, at 0 when none of it is here. |
| `characters.<id>.*`                                  | group               | A copy here, with the names of [Characters](#characters).                                                                 |

Effects reach them with the same names ([Syntax](09-syntax.md#changing-the-party-effects)): `present.wolf: 2` (two more wolves), `present.wolf.values.health: -1` (every wolf here), `present.all.conditions.routed: true` (everyone here), `characters.wolf-2.values.health: -1` (one). Copies the party left behind aren't here, and those whose template says `behind: leave` are gone; a copy with a condition that `leaves` is gone at once.

## Discovering the map

- The **terrain** table sees the cell the party is on (its terrain, tags, values and region), plus `place.id` (the cell being decided), `from` (the one it's seen from: `from.id`, `from.terrain`…) and the land around the cell being decided: `around` counts its known neighbours' terrains (`around.lake: 2`), `aroundCount` how many are known, `common` the most frequent terrain (a tie goes to the one it's seen from) and `commonCount` how many have it.
- The **contents** table sees the cell being entered (`place.terrain`, `place.tags`… and `terrain` for short).
- Both see the party stats, `party` and today's values.

## Which value wins

When two sources give the same name, the later one wins:

1. **Checks:** party stats by name → today's values → the map and trip facts → `party` → the binding's context. So a stat or a value of the day called `terrain` or `weather` can't hide the real one; `party.stats.terrain` still reaches it. **Full names never collide**: `place.terrain`, `trip.weather`, `party.stats.weather` are always what they say; only short names are shared. Reserved names a stat shouldn't use: the short names in the tables above, and the groups `hex`, `time`, `system`, `trip`, `world`, `party`, `today`, `yesterday`, `from`, `around`, `characters`, `acting`, `roles`, `factions`, `faction`, `icon`, `token`, `name`; in a table with a roll, `roll` and `result`.
2. **Hand rolls** (Oracle panel): during a trip, the same order as checks; then the token → what you type in the roll panel's **Context**. A typed `token.fare` changes only that value of the token.
3. **Inside a table:** values an entry sets (`set`) reach the table it then rolls; a generator's fields see the fields before them, and a field's `context` adds values for that field only.

Some collisions, and what happens:

- **A region value and a cell value** with the same name (`danger: 2` on the Greywood, `danger: 5` on one of its cells): the cell's wins there, the region's everywhere else. That's how the Grey Marches make the forest more dangerous towards its heart.
- **A stat called like a fact** (a stat `weather`, or `terrain`): `{{trip.weather}}` and `when: { trip.weather: storm }` read the day's weather, never the stat; the stat is still `party.stats.weather`. Better not to use those names (the list above).
- **A value of an icon or token called `terrain`**: it's read as `icon.terrain` / `token.terrain`, inside its own name, so it can't hide the cell's terrain.
- **A value an entry sets with a stat's name** (`set: { morale: 1 }` with a stat `morale`): the result's text and the tables it rolls read `{{morale}}` as 1, but it doesn't change the stat, and it doesn't stay for the day (only `weather` and the declared values do). To change the stat, use `effects: { party.stats.morale: 1 }`.
- **A binding's context** (`context: { timeOfDay: night }`) wins over everything for its check: it's how the same table answers day and night encounters.

## Kinds of value, in detail

- Values written on the map (a cell's, a region's, an icon's, a token's) are read as in YAML: `3`, `-1`, `2.5` are **numbers** (they add up in dice and compare with `gt` / `gte` / `lt` / `lte`), `true` and `false` are **yes/no**, anything else is **text** (`Brenna`, `3 silver`).
- In dice, a missing value counts as **0**: `1d6 + {{place.danger}}` works where there's no danger.
- In conditions, a missing value doesn't match, except with `exists: false` or `not`; a comparison with a value that isn't a number never holds. Every operator, with examples: [Conditions](08-conditions.md).
- A **list** matches when it has the value asked for (`place.tags: ford`), or any of several (`place.tags: [ford, bridge]`).
- Names with dots read inside a group: `token.fare`, `icon.guards`, `npc.role` (a generator's field).

The Grey Marches use every one of these; [The Grey Marches](../packs/02-grey-marches.md) says where.
