# Installing and playing offline

Every OpenTabletop app can be **installed** like a program and works **without a connection** once it has been opened.

## Installing

Open the app in your browser and use the browser's install option: in Chrome, Edge or Brave, the install icon in the address bar (or menu → **Install**); on a phone, **Add to home screen**. Firefox on the desktop doesn't install web apps, but everything below works in it too.

Each app installs on its own (Hexmapper, Oracle, Travel, Manual). Installed apps open in their own window, with their own icon.

## Offline

The first visit keeps a copy of the app in the browser. From then on it opens and works with no connection: maps, packs, trips and rolls all live in the browser anyway. When there is a new version, it is fetched in the background and used from the next time you open the app.

## Your data stays where it was

Installing changes nothing about where your data lives: in the browser, for the site the apps are served from. An installed app and the same app in a tab share the same maps and packs. To move them elsewhere or keep a copy, see [Backups of everything](05-backups.md).
