# Keyboard shortcuts

You don't need this page open to find them: Map shows its keys where you use them.

- Press <kbd>?</kbd>, or the keyboard in the top bar, for **Keyboard shortcuts**: every key of Map by what it's for, and the ones every app shares.
- Hover a button to see its key beside its name (_Terrain_ <kbd>B</kbd>, _Undo_ <kbd>Ctrl</kbd>+<kbd>Z</kbd>).
- A tool with keys of its own lists them at the foot of its panel, under **Keys of …** (_Keys of Terrain_): a click unfolds them, and Map remembers whether you keep them open.

## Tools

| Key                                        | Tool                          |
| ------------------------------------------ | ----------------------------- |
| <kbd>V</kbd>                               | Select                        |
| <kbd>B</kbd> / <kbd>G</kbd> / <kbd>E</kbd> | Terrain: brush / fill / erase |
| <kbd>N</kbd>                               | Regions                       |
| <kbd>L</kbd>                               | Factions                      |
| <kbd>R</kbd>                               | Roads and rivers              |
| <kbd>W</kbd>                               | Walls                         |
| <kbd>C</kbd>                               | Connections                   |
| <kbd>I</kbd>                               | Icons                         |
| <kbd>T</kbd>                               | Text                          |
| <kbd>K</kbd>                               | Tokens                        |

In Play, only <kbd>V</kbd> picks a tool: the tools that edit the map have no keys there, so a slip can't turn a click into a stroke.

## The view

| Key                                                   | Does                                    |
| ----------------------------------------------------- | --------------------------------------- |
| <kbd>P</kbd>                                          | Edit or Play (the switch at the top)    |
| <kbd>Space</kbd>+drag, or drag with the middle button | Move the map                            |
| Wheel                                                 | Zoom                                    |
| <kbd>F</kbd>                                          | Fit the map                             |
| <kbd>O</kbd>                                          | The Oracle panel                        |
| <kbd>?</kbd>                                          | Keyboard shortcuts (every app has them) |
| <kbd>F1</kbd>, in a field                             | Its explanation, in the help column     |

## Editing

| Key                                                                           | Does                                                               |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>                                                  | Undo                                                               |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo                                                               |
| <kbd>Ctrl</kbd>+<kbd>S</kbd>                                                  | Save                                                               |
| <kbd>Ctrl</kbd>+<kbd>O</kbd>                                                  | Open a map file                                                    |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd>                                     | Remove the selected icon, label, token or connection               |
| Right click                                                                   | Remove what's under the cursor (an icon, label, token, connection) |
| <kbd>Esc</kbd>                                                                | Let go of what's selected                                          |

## Terrain

| Key                         | Does                               |
| --------------------------- | ---------------------------------- |
| <kbd>[</kbd> / <kbd>]</kbd> | Smaller / bigger brush             |
| <kbd>Shift</kbd>+drag       | Paint a rectangle (a room at once) |
| <kbd>Ctrl</kbd>+click       | Pick the terrain under the cursor  |
| Right click                 | Erase                              |

Regions take <kbd>Shift</kbd>+drag and <kbd>Ctrl</kbd>+click the same way.

**Drawing with the keyboard** ([Terrain](02-terrain.md#drawing-with-the-keyboard)): an arrow extends a corridor from the selected cell, <kbd>Shift</kbd>+arrow only moves, <kbd>R</kbd> paints a room round the cell, <kbd>D</kbd> a door to the cell it came from, <kbd>Esc</kbd> lets go (and <kbd>R</kbd> is Roads and rivers again).

## Roads and rivers

| Key                                    | Does                                      |
| -------------------------------------- | ----------------------------------------- |
| <kbd>Enter</kbd> or right click        | Finish the line                           |
| <kbd>Backspace</kbd>                   | Remove its last point                     |
| <kbd>Esc</kbd>                         | Cancel the line                           |
| <kbd>Shift</kbd>+click                 | A point where you click, off the centre   |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+click | A point where you click, with no snapping |

## Playing

| Key                                                            | Does                                                              |
| -------------------------------------------------------------- | ----------------------------------------------------------------- |
| Arrows, or <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | On a trip: the party steps one cell that way ([Play](08-play.md)) |
