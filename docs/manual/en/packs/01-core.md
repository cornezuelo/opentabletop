# Core

**Core** is the generic pack every app ships with: tools for any game, with no setting, and the **Generic rules**, the smallest travel system, the one a map plays when it chooses none. It's MIT-licensed, written in English with a Spanish translation.

| Definition                                      | What it's for                                                                                                                                                                          |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Yes or no?** (oracle)                         | Ask a yes/no question and choose how likely it is. The classic solo-play oracle.                                                                                                       |
| **How do they take it?** (oracle)               | How someone answers a request: the bigger the ask, the harder the yes. Every answer comes with a **Motive**.                                                                           |
| **Prompt** (generator)                          | An action and a subject (`{{action.text}} {{subject.text}}`) to spark an idea when you're stuck.                                                                                       |
| **Scene twist** (table)                         | At the start of a scene: on a 1 it doesn't go as expected. Offers advantage when things are calm, disadvantage when tension is high.                                                   |
| **Advantage** and **Disadvantage** (roll modes) | Roll twice and keep the higher or the lower total. Core's tables offer them, and so can any pack that depends on Core (`modes: [advantage, disadvantage]`).                            |
| **Twists** and **Complications**                | What changes, and a deck of complications to draw from (a card stays out until you reshuffle).                                                                                         |
| **A faction's turn** (table)                    | What a faction does on a world turn, for any game: expands (+1 hex), holds, schemes or loses ground. A system's factions roll it with `turn: core/faction-turn`.                       |
| **A growing threat** (clocks)                   | A progress clock for any game: the threat grows a segment at a time and, when full, strikes with one of the **Twists** and starts over. A system brings it with `clocks: core/threat`. |

## The Generic rules

Core's system (`system.yaml`, `id: default`, so its id is `core`) is the smallest one that plays: a map that chooses no system plays it (**Map settings → Map → System**), and so do maps and trips of older versions that played the rules built into the apps. Like any bundled system, the Systems app shows it read-only; **New system** starts from a copy of its rules, to change as you like. For one that uses everything, see [The Grey Marches](02-grey-marches.md).

| Part                                     | What it does, and which feature it shows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Generic rules** (system)               | Names its parts: `travel: default`, `calendar: default`, `sheet: character`, `partySheet: party`. A system that names no `travel` doesn't travel; this one does.                                                                                                                                                                                                                                                                                                                                                                       |
| **Travel rules** (`travel.yaml`)         | Played at 10 km a hex (`travel: { hexKm: 10 }`), on foot (30 km a day) or on horseback (50 km), across the terrains of the Hexmapper's palettes, faster on roads and trails; water isn't crossed, and a lake only on the ice in winter (`passable: { when: { time.season: winter } }`). Its day is named by its calendar's parts: trips start as the morning begins (`start: part.morning`), and a party that can't march camps from the night (`halt: { at: part.night, do: camp }`). One supply, **Food**, never below 0 (`min: 0`). |
| **March**, **Camp**, **Rest**, **Eat**   | Four actions made of steps. **March** walks while it isn't dark for the day's 8 hours (`when: { time.tags: { not: dark }, trip.marched: { lt: '{{system.hoursPerDay}}' } }`), to the destination or one hex (a parameter, `travel.move: '{{params.until}}'`), and the trip takes it when it goes on by itself (`travel.onward`). **Camp** sleeps until the morning (`time: part.morning`); **Rest** is an hour, only by day; **Eat** is taken by the system itself as each day ends (`on: day-end`), using 1 food.                     |
| **The plain calendar** (`calendar.yaml`) | Four seasons of 90 days, one month each; a day in four parts (morning from 06:00, afternoon, evening, night from 20:00, tagged `dark`: `time.part`, `time.tags`) and six watches of four hours (`time.watch`, 1 to 6; the World panel's **Next: …**).                                                                                                                                                                                                                                                                                  |
| **Character** and **Party** (sheets)     | The smallest sheets: a character's **Health** (3, never below 0 nor above 3) and **Wounded**, for you to track by hand; the party's own **Morale** (3, from 0 to 5), drawn as a track. The smallest characters for the roster too: **New character** in the [Characters app](../characters/01-getting-started.md) with the Generic rules makes one, and a trip with them takes it with **From the roster**.                                                                                                                            |

Other packs depend on Core (the Grey Marches use its tables), so it isn't copied in place: **Duplicate as a new pack** in the Oracle app makes a pack of yours from it (`core-mine`), to change as you like, while the bundled Core stays for the packs that need it and keeps its updates. A copy of Core made by an older version still replaces it; the Systems app says when a system uses one older than the bundled Core and lets you take its changes.
