# Keyboard shortcuts

| Key                                                                          | Action                                            |
| ---------------------------------------------------------------------------- | ------------------------------------------------- |
| <kbd>V</kbd>                                                                 | Select                                            |
| <kbd>B</kbd> / <kbd>G</kbd> / <kbd>E</kbd>                                   | Terrain: brush / fill / erase                     |
| <kbd>[</kbd> <kbd>]</kbd>                                                    | Smaller / bigger brush                            |
| <kbd>N</kbd>                                                                 | Regions                                           |
| <kbd>R</kbd>                                                                 | Roads and rivers                                  |
| <kbd>I</kbd>                                                                 | Icons                                             |
| <kbd>T</kbd>                                                                 | Text                                              |
| <kbd>K</kbd>                                                                 | Tokens                                            |
| <kbd>P</kbd>                                                                 | Play                                              |
| <kbd>O</kbd>                                                                 | Oracle panel                                      |
| <kbd>F</kbd>                                                                 | Fit the map                                       |
| <kbd>Space</kbd> + drag, middle button                                       | Pan                                               |
| Wheel                                                                        | Zoom                                              |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo                                       |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>O</kbd>                  | Save / open a file                                |
| <kbd>Delete</kbd>                                                            | Remove the selected icon, label or token          |
| <kbd>Esc</kbd>                                                               | Deselect, cancel a line                           |
| <kbd>Enter</kbd> / <kbd>Backspace</kbd>                                      | Finish a line / remove its last point             |
| <kbd>Ctrl</kbd>+click                                                        | Pick the terrain, region or icon under the cursor |
