# Core

**Core** es el pack genérico que traen todas las aplicaciones: herramientas para cualquier partida, sin ambientación, y las **reglas genéricas**, el sistema de viaje más pequeño, el que juega un mapa que no elige ninguno. Tiene licencia MIT y está escrito en inglés, con traducción al español.

| Definición                                     | Para qué sirve                                                                                                                                                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **¿Sí o no?** (oráculo)                        | Haz una pregunta de sí o no y elige lo probable que es. El oráculo clásico del juego en solitario.                                                                                                           |
| **¿Cómo se lo toman?** (oráculo)               | Cómo responde alguien a una petición: cuanto más pides, más difícil es el sí. Cada respuesta trae un **Motivo**.                                                                                             |
| **Inspiración** (generador)                    | Una acción y un asunto (`{{action.text}} {{subject.text}}`) para sacar una idea cuando te atascas.                                                                                                           |
| **Giro de escena** (tabla)                     | Al empezar una escena: con un 1 no sale como esperabas. Ofrece ventaja cuando todo está tranquilo y desventaja cuando hay tensión.                                                                           |
| **Ventaja** y **Desventaja** (modos de tirada) | Tirar dos veces y quedarse con el total más alto o el más bajo. Las ofrecen las tablas de Core, y cualquier pack que dependa de Core (`modes: [roll-modes.advantage, roll-modes.disadvantage]`).             |
| **Giros** y **Complicaciones**                 | Qué cambia, y un mazo de complicaciones del que robar (una carta no vuelve hasta que barajas).                                                                                                               |
| **El turno de una facción** (tabla)            | Lo que hace una facción en un turno del mundo, para cualquier juego: se expande (+1 hex), aguanta, conspira o pierde terreno. Las facciones de un sistema la tiran con `turn: core/table.faction-turn`.      |
| **Una amenaza que crece** (relojes)            | Un reloj de progreso para cualquier juego: la amenaza crece de segmento en segmento y, al llenarse, golpea con uno de los **Giros** y vuelve a empezar. Un sistema lo trae con `clocks: core/clocks.threat`. |

## Las reglas genéricas

El sistema de Core (`system.yaml`, `id: default`, así que su id es `core`) es el más pequeño que se juega: lo juega un mapa cuya campaña no elige sistema (**Ajustes del mapa → Campaña → Sistema**), y también los mapas y viajes de versiones anteriores que jugaban las reglas integradas en las aplicaciones. Como cualquier sistema incluido, la aplicación Systems lo enseña en solo lectura; **Nuevo sistema** empieza con una copia de sus reglas, para cambiarla a tu gusto. Para uno que lo usa todo, mira [Las Marcas Grises](02-grey-marches.md).

| Parte                                                            | Qué hace y qué enseña                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Reglas genéricas** (sistema)                                   | Nombra sus partes: `travel: travel-rules.default`, `bindings: bindings.default`, `calendar: calendar.default`, `weather: [weather.default]`, `sheet: sheet.character`, `partySheet: sheet.party`, `items: [items.gear]`. Un sistema que no nombra `travel` no viaja; este sí.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Reglas de viaje** (`travel.yaml`)                              | Se juega a 10 km por hex (`travel: { hexKm: 10 }`), a pie (30 km al día) o a caballo (50 km), por los terrenos de las paletas del Hexmapper, más deprisa por caminos y senderos; el agua no se cruza, y un lago solo sobre el hielo en invierno (`passable: { when: { time.season: winter } }`). Su día se nombra por las partes de su calendario: los viajes empiezan al empezar la mañana (`start: time.part.morning`) y un grupo que no puede marchar acampa desde la noche (`halt: { at: time.part.night, do: actions.camp }`). La comida es un valor de la hoja del grupo (abajo), que se come un día cada vez al acabar cada día. Una comprobación, **Clima** (`WEATHER_CHECK_REQUIRED`), al empezar cada mañana (`at: time.part.morning`), que los bindings tiran en _El cielo sencillo_ (`weather: weather.default`); con lluvia la marcha va a ×0.75, con tormenta o nieve a ×0.5 (`weather: { rain: { speed: 0.75 } … }`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Marchar**, **Acampar**, **Descansar**, **Comer**, **Explorar** | Cinco acciones hechas de pasos. **Marchar** camina mientras no es de noche las 8 horas del día (`when: { time.tags: { not: dark }, trip.marched: { lt: '{{system.hoursPerDay}}' } }`), hasta el destino o un hex (un parámetro, `travel.move: '{{params.until}}'`), y el viaje la hace cuando sigue por sí solo (`travel.onward`). **Acampar** duerme hasta la mañana (`time: time.part.morning`); **Descansar** es una hora, solo de día; **Comer** la hace el propio sistema al acabar cada día (`on: time.day-end`), gastando 1 de la comida de la hoja del grupo (`party.values.food: -1`), y cuando no quedaba el diario dice «No queda nada que comer.» (un paso `say` con su propia condición, `when: { trip.below: party.values.food }`: un paso posterior ve lo que cambió el anterior). **Explorar** es una hora de día y luego una idea de lo que encuentra el grupo, tirada en la **Inspiración** de Core (`roll: generator.prompt`: un paso que tira algo del Oráculo, con su resultado en el diario por su nombre). Las reglas genéricas no tienen relojes de progreso, así que tampoco momentos del mundo (`world.clocks.<id>.full`): los enseñan las Marcas Grises. Los pasos que esperan al jugador (`pause`, `ask`), cambian la forma de viajar o esperan algo quedan para los sistemas que los necesiten (el transbordador de las Marcas Grises): mira [Acciones y pasos](../technical/10-actions-and-steps.md). |
| **Desesperación**                                                | El momento escrito como condición más pequeño (una reacción): cuando la moral del grupo llega a 0 (`on: { when: { party.values.morale: { lte: 0 } } }`), sea lo que sea lo que la bajó, el viaje se detiene (`pause:`) para que decidas; una vez, hasta que la moral suba y vuelva a llegar a 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **El cielo sencillo** (`weather.yaml`)                           | El modelo de clima más pequeño para cualquier ambientación: despejado, nublado, lluvia, tormenta y, solo en invierno, nieve; el de hoy sigue al de ayer con tablas de probabilidad por estación (`next`), así que la lluvia dura unos días y las tormentas pasan. Un clima que una estación no incluye (la nieve en primavera) vuelve a empezar desde el `start` de la estación. Enseña el [clima con inercia](../systems/12-weather.md); las Marcas Grises enseñan también una flor hexagonal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **El calendario sencillo** (`calendar.yaml`)                     | Cuatro estaciones de 90 días, un mes cada una; un día en cuatro partes (la mañana desde las 06:00, la tarde, el atardecer y la noche desde las 20:00, con la etiqueta `dark`: `time.part`, `time.tags`) y seis guardias de cuatro horas (`time.watch`, de 1 a 6; el **Siguiente: …** del panel Mundo).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Personaje** y **Grupo** (hojas)                                | Las hojas más pequeñas: la **Salud** de un personaje (3, nunca por debajo de 0 ni por encima de 3, dibujada como barra) y **Herido**, para llevarlos a mano, con las dos partes que se mantienen por sí solas en su forma más pequeña: el **Daño**, que sale de la Salud (`from: '{{3 - self.values.health}}'`), y **Caído**, mientras la Salud sea 0 (`when: { self.values.health: { lte: 0 } }`); la **Moral** del propio grupo (3, de 0 a 5), dibujada como casillas (`display: boxes`), y su **Comida** (6 en un viaje nuevo, nunca por debajo de 0): lo que lleva el grupo, como un simple valor de su hoja, la forma más pequeña. También los personajes más pequeños del plantel: **Nuevo personaje** en la [aplicación Characters](../characters/01-getting-started.md) con las reglas genéricas crea uno, y un viaje con ellas lo trae con **Del plantel**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Equipo** (`items.yaml`)                                        | El catálogo de objetos más pequeño: una cuerda, una antorcha y una ración, con etiquetas (`climbing`, `light`, `food`), en una hoja que no da a los objetos campos ni lugares, así que son una lista con cantidades. **Añadir un objeto** en la tarjeta de un personaje los ofrece; los efectos pueden darlos (`acting.items.torch: 1`). Enseña los [objetos](../systems/08-items.md); las Marcas Grises enseñan campos, lugares y contenedores.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

**En una campaña.** Una [campaña](../campaign/01-getting-started.md) que juega las Reglas genéricas (una nueva en la aplicación Campaign, o cualquier mapa cuya campaña no elige sistema) tiene un reloj del mundo con el calendario sencillo: su fecha por estaciones, **Siguiente: …** por sus partes del día y sus guardias, su clima tirado día a día en _El cielo sencillo_ (el de un viaje, mientras hay uno en marcha), y los eventos y relojes de progreso que añadas a mano. Las Reglas genéricas no declaran facciones ni relojes propios, porque los poderes y las amenazas son de un mundo concreto: un sistema tuyo trae **Una amenaza que crece** de Core (`clocks: core/clocks.threat`) y da a sus facciones **El turno de una facción** (`turn: core/table.faction-turn`). Para una campaña con todo (dos mapas, facciones, relojes, eventos), mira [Las Marcas Grises](02-grey-marches.md).

Otros packs dependen de Core (las Marcas Grises usan sus tablas), así que no se copia en su sitio: **Duplicar como pack nuevo** en la aplicación Oracle hace un pack tuyo a partir de él (`core-mine`), para cambiarlo a tu gusto, mientras el Core incluido se queda para los packs que lo necesitan y conserva sus actualizaciones. Una copia de Core hecha con una versión anterior todavía lo sustituye; la aplicación Systems avisa cuando un sistema usa una más antigua que el Core incluido y te deja coger sus cambios.
