# Core

**Core** es el pack genérico que traen todas las aplicaciones: herramientas para cualquier partida, sin ambientación, y las **reglas genéricas**, el sistema de viaje más pequeño, el que juega un mapa que no elige ninguno. Tiene licencia MIT y está escrito en inglés, con traducción al español.

| Definición                                     | Para qué sirve                                                                                                                                                                                        |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **¿Sí o no?** (oráculo)                        | Haz una pregunta de sí o no y elige lo probable que es. El oráculo clásico del juego en solitario.                                                                                                    |
| **¿Cómo se lo toman?** (oráculo)               | Cómo responde alguien a una petición: cuanto más pides, más difícil es el sí. Cada respuesta trae un **Motivo**.                                                                                      |
| **Inspiración** (generador)                    | Una acción y un asunto (`{{action.text}} {{subject.text}}`) para sacar una idea cuando te atascas.                                                                                                    |
| **Giro de escena** (tabla)                     | Al empezar una escena: con un 1 no sale como esperabas. Ofrece ventaja cuando todo está tranquilo y desventaja cuando hay tensión.                                                                    |
| **Ventaja** y **Desventaja** (modos de tirada) | Tirar dos veces y quedarse con el total más alto o el más bajo. Las ofrecen las tablas de Core, y cualquier pack que dependa de Core (`modes: [advantage, disadvantage]`).                            |
| **Giros** y **Complicaciones**                 | Qué cambia, y un mazo de complicaciones del que robar (una carta no vuelve hasta que barajas).                                                                                                        |
| **El turno de una facción** (tabla)            | Lo que hace una facción en un turno del mundo, para cualquier juego: se expande (+1 hex), aguanta, conspira o pierde terreno. Las facciones de un sistema la tiran con `turn: core/faction-turn`.     |
| **Una amenaza que crece** (relojes)            | Un reloj de progreso para cualquier juego: la amenaza crece de segmento en segmento y, al llenarse, golpea con uno de los **Giros** y vuelve a empezar. Un sistema lo trae con `clocks: core/threat`. |

## Las reglas genéricas

El sistema de Core (`system.yaml`, `id: default`, así que su id es `core`) es el más pequeño que se juega: lo juega un mapa cuya campaña no elige sistema (**Ajustes del mapa → Campaña → Sistema**), y también los mapas y viajes de versiones anteriores que jugaban las reglas integradas en las aplicaciones. Como cualquier sistema incluido, la aplicación Systems lo enseña en solo lectura; **Nuevo sistema** empieza con una copia de sus reglas, para cambiarla a tu gusto. Para uno que lo usa todo, mira [Las Marcas Grises](02-grey-marches.md).

| Parte                                              | Qué hace y qué enseña                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Reglas genéricas** (sistema)                     | Nombra sus partes: `travel: default`, `calendar: default`, `sheet: character`, `partySheet: party`. Un sistema que no nombra `travel` no viaja; este sí.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Reglas de viaje** (`travel.yaml`)                | Se juega a 10 km por hex (`travel: { hexKm: 10 }`), a pie (30 km al día) o a caballo (50 km), por los terrenos de las paletas del Hexmapper, más deprisa por caminos y senderos; el agua no se cruza, y un lago solo sobre el hielo en invierno (`passable: { when: { time.season: winter } }`). Su día se nombra por las partes de su calendario: los viajes empiezan al empezar la mañana (`start: part.morning`) y un grupo que no puede marchar acampa desde la noche (`halt: { at: part.night, do: camp }`). Un suministro, **Comida**, que nunca baja de 0 (`min: 0`).                                                                                                                                                                                                                                                                                                                                              |
| **Marchar**, **Acampar**, **Descansar**, **Comer** | Cuatro acciones hechas de pasos. **Marchar** camina mientras no es de noche las 8 horas del día (`when: { time.tags: { not: dark }, trip.marched: { lt: '{{system.hoursPerDay}}' } }`), hasta el destino o un hex (un parámetro, `travel.move: '{{params.until}}'`), y el viaje la hace cuando sigue por sí solo (`travel.onward`). **Acampar** duerme hasta la mañana (`time: part.morning`); **Descansar** es una hora, solo de día; **Comer** la hace el propio sistema al acabar cada día (`on: day-end`), gastando 1 de comida, y cuando no quedaba el diario dice «No queda nada que comer.» (un paso `say` con su propia condición, `when: { trip.below: food }`). Los pasos que esperan al jugador (`pause`, `ask`), cambian la forma de viajar o esperan algo quedan para los sistemas que los necesiten (el transbordador de las Marcas Grises): mira [Acciones y pasos](../technical/10-actions-and-steps.md). |
| **El calendario sencillo** (`calendar.yaml`)       | Cuatro estaciones de 90 días, un mes cada una; un día en cuatro partes (la mañana desde las 06:00, la tarde, el atardecer y la noche desde las 20:00, con la etiqueta `dark`: `time.part`, `time.tags`) y seis guardias de cuatro horas (`time.watch`, de 1 a 6; el **Siguiente: …** del panel Mundo).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Personaje** y **Grupo** (hojas)                  | Las hojas más pequeñas: la **Salud** de un personaje (3, nunca por debajo de 0 ni por encima de 3) y **Herido**, para llevarlos a mano; la **Moral** del propio grupo (3, de 0 a 5), dibujada como contador. También los personajes más pequeños del plantel: **Nuevo personaje** en la [aplicación Characters](../characters/01-getting-started.md) con las reglas genéricas crea uno, y un viaje con ellas lo trae con **Del plantel**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

**En una campaña.** Una [campaña](../campaign/01-getting-started.md) que juega las Reglas genéricas (una nueva en la aplicación Campaign, o cualquier mapa cuya campaña no elige sistema) tiene un reloj del mundo con el calendario sencillo: su fecha por estaciones, **Siguiente: …** por sus partes del día y sus guardias, y los eventos y relojes de progreso que añadas a mano. Las Reglas genéricas no declaran facciones ni relojes propios, porque los poderes y las amenazas son de un mundo concreto: un sistema tuyo trae **Una amenaza que crece** de Core (`clocks: core/threat`) y da a sus facciones **El turno de una facción** (`turn: core/faction-turn`). Para una campaña con todo (dos mapas, facciones, relojes, eventos), mira [Las Marcas Grises](02-grey-marches.md).

Otros packs dependen de Core (las Marcas Grises usan sus tablas), así que no se copia en su sitio: **Duplicar como pack nuevo** en la aplicación Oracle hace un pack tuyo a partir de él (`core-mine`), para cambiarlo a tu gusto, mientras el Core incluido se queda para los packs que lo necesitan y conserva sus actualizaciones. Una copia de Core hecha con una versión anterior todavía lo sustituye; la aplicación Systems avisa cuando un sistema usa una más antigua que el Core incluido y te deja coger sus cambios.
