# Lo que ven las tablas

Cada tirada recibe un **contexto**: valores que una tabla puede usar en sus dados (`{{place.danger}}`), sus textos y sus condiciones (`when: { place.danger: { gte: 2 } }`). Esta página es la referencia de cada valor: su nombre, qué tipo de valor es, los valores que puede tomar y de dónde salen (y dónde verlos en las aplicaciones). Al final, cuál gana cuando dos tienen el mismo nombre.

## Cómo leer esta página

Cada valor tiene un **nombre completo** que dice de dónde sale (`place.terrain`) y casi todos también un **nombre corto** (`terrain`). Los dos leen el mismo valor: `terrain: forest` y `place.terrain: forest` se cumplen en los mismos hexes, y `{{season}}` escribe lo mismo que `{{time.season}}`.

| Nombres completos    | De qué tratan                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `place.*`            | [el sitio](#el-sitio-place): su id, terreno, etiquetas, región, icono y sus propios valores       |
| `time.*`             | [el momento](#el-momento-time): estación, día, hora, las partes del día y el calendario           |
| `system.*`           | [el día del propio sistema](#el-dia-del-sistema-system), como números                             |
| `trip.*`             | [el viaje](#el-viaje-trip): su día, la forma de viajar, el clima, lo que ha hecho                 |
| `world.*`            | [el reloj del mundo](#el-mundo-world-y-las-facciones) (el de la campaña)                          |
| `party.*`            | [el grupo](#el-grupo-party): sus características, su hoja, sus objetos y personajes               |
| `present.*`          | [los presentes](#los-presentes-present): copias de las plantillas del sistema donde está el grupo |
| `today.*`            | [los valores del día](#los-valores-del-dia-today-yesterday), y `yesterday.*` los del día anterior |
| `from.*`, `around.*` | [el hex que se deja y los de alrededor](#alrededor-del-grupo-from-around)                         |

- **Los nombres cortos** se escriben antes, y son los que escribes en la caja **Contexto** del Oráculo: `terrain: forest` ahí también rellena `place.terrain`.
- **Los nombres completos** no se pueden tapar: una característica del grupo, un valor del día o el contexto de un binding llamado `weather` o `day` ocupa el nombre corto (ver [Qué valor gana](#que-valor-gana)), nunca el completo. Las reglas de viaje de las Marcas Grises y las reglas genéricas los usan.

**Tipos de valor** en las tablas de abajo: un **número** (`3`, `14.5`: se suma en los dados y se compara con `gt` / `gte` / `lt` / `lte`), **sí/no** (`true` / `false`), **texto**, un **id** (un texto que declara el sistema o el mapa: `forest`, `market-day`), una **lista** (varios ids a la vez: una condición se cumple si la lista tiene el que se pide, `place.tags: landmark`) o un **grupo** (nombres dentro: `place.icon.guards`). Un valor que no está cuenta como **0** en los dados y **no cumple** en las condiciones (salvo con `exists: false` o `not`): mira [Condiciones](08-conditions.md).

**Dónde** dice qué aplicaciones lo dan: **Mapa** (un mapa: el hex seleccionado, o el del grupo en un viaje), **Viajes** (un viaje sin mapa: una fila de hexes, cada uno con su terreno, sus etiquetas y los caminos hasta el siguiente), **viaje** (un viaje en cualquiera de las dos), **tiradas a mano** (el panel o la aplicación Oráculo).

## El sitio, `place.*`

Donde está el grupo (hoy, siempre un hex): el hex seleccionado, el del grupo en un viaje, o del hex del que trata una comprobación (al que se entra, en el que se hace una acción).

| Nombre completo                           | Corto     | Tipo                  | Valores, y de dónde salen                                                                                                                                                                                                                                                                                    |
| ----------------------------------------- | --------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `place.id`                                | —         | id                    | La clave del hex: columna y fila contadas desde 0 (`"4,2"`), sea cual sea el formato de coordenadas del mapa (`0503`). Está junto a las coordenadas en el panel del hex. En Viajes, su lugar en el camino (`"0"`, `"1"`…).                                                                                   |
| `place.terrain`                           | `terrain` | id                    | El id del terreno (`forest`, `dense-forest`, `lake`…), nunca su nombre, en ningún idioma. La paleta del mapa decide cuáles hay: **Editar paleta** enseña cada id, y el panel del hex el del hex. No está en un hex en blanco.                                                                                |
| `place.water`                             | `water`   | sí/no                 | `true` cuando el terreno está marcado como **Agua** en la paleta (en Viajes: `lake`, `sea`, `deep-sea`). `false` si no.                                                                                                                                                                                      |
| `place.tags`                              | `tags`    | lista de textos       | Las etiquetas del hex (`landmark`, `ford`, `shrine`…): lo que escribas en sus **Etiquetas** (sugiere las que ya se usan en el mapa). Lista vacía si no tiene.                                                                                                                                                |
| `place.region`                            | `region`  | texto                 | El **nombre** de la región tal como está escrito (`Ashford Vale`), no su id. Solo en Mapa. La herramienta **Regiones** las lista.                                                                                                                                                                            |
| `place.<valor>`                           | `<valor>` | número, sí/no o texto | Cada valor de la **región** del hex, y luego los **del propio hex** (el del hex gana con el mismo nombre): `danger`, `elevation`… Escrito como `3` es un número, `true` / `false` sí/no, lo demás texto. El panel del hex lista los suyos y, debajo, los que le vienen de su región. Solo en Mapa.           |
| `place.name`                              | `name`    | texto                 | El nombre del hex, si tiene. Solo en Mapa.                                                                                                                                                                                                                                                                   |
| `place.icon`                              | `icon`    | grupo                 | El icono del hex: `icon.id`, su id (`game:castle`; las imágenes importadas `asset:<id>`: se ve bajo la paleta de la herramienta Iconos, en sus ayudas y en el panel del hex), y cada uno de sus valores por nombre (`icon.guards`), con los tipos de arriba. No está si el hex no tiene icono. Solo en Mapa. |
| `place.faction`                           | —         | id                    | El id de la facción que tiene el hex (`iron-clans`), con facciones en el mapa. Solo en Mapa.                                                                                                                                                                                                                 |
| `place.pois`                              | —         | lista de ids          | Los ids de los lugares (PDI) del hex: a los que apuntan las relaciones de los personajes (`poi:<id>`). Solo en Mapa.                                                                                                                                                                                         |
| `place.related`, `place.relations.<tipo>` | —         | lista de ids          | Los personajes unidos al hex, a su región o a un lugar en él, según sus relaciones (`place.related: mara`); por tipo de relación (`place.relations.home: mara`). Mira [Personajes](#personajes).                                                                                                             |

Ejemplos: `when: { place.terrain: [forest, dense-forest] }` (cualquiera de los dos), `when: { place.tags: ford }`, `when: { place.danger: { gte: 3 } }`, `when: { place.icon.id: game:castle }`, `'1d6 + {{icon.guards}}'`, `when: { place.region: Ashford Vale }`.

Los puntos de interés guardan sus valores en el mapa y en su fichero, pero las tablas no los leen: un hex puede tener varios.

**El token seleccionado** (tiradas a mano desde el panel Oráculo de Mapa), `token.*`:

| Nombre                            | Tipo           | Valores, y de dónde salen                                                                                                                           |
| --------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `token.name`                      | texto          | Su nombre.                                                                                                                                          |
| `token.kind`                      | id             | `pc`, `npc`, `enemy` o `party` (el **Tipo** de su panel).                                                                                           |
| `token.<valor>`                   | como `place.*` | Cada valor escrito en su panel (`token.fare`).                                                                                                      |
| `token.values.<id>`, `token.<id>` | número         | Con **hoja** (Darle una hoja): cada valor de la hoja (`token.values.health`, también `token.health`); los ids, los que declara la hoja del sistema. |
| `token.conditions`, `token.tags`  | lista de ids   | Los estados de su hoja que tiene ahora (`token.conditions: wounded`), y sus etiquetas.                                                              |
| `token.relations.<tipo>`          | lista          | Sus relaciones por tipo, como las de un personaje.                                                                                                  |

## El momento, `time.*`

En un viaje, y en las tiradas a mano mientras hay un viaje o el reloj del mundo en marcha.

| Nombre completo   | Corto        | Tipo              | Valores, y de dónde salen                                                                                                                                                                                                                                                                                                                         |
| ----------------- | ------------ | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `time.season`     | `season`     | id                | `spring`, `summer`, `autumn`, `winter`; con un calendario propio del sistema, las estaciones que nombran sus meses (Sistemas → **Calendario**).                                                                                                                                                                                                   |
| `time.day`        | `day`        | número            | El número de día desde el inicio del calendario (1, 2…).                                                                                                                                                                                                                                                                                          |
| `time.hour`       | `hour`       | número            | La hora con los minutos como fracción: `14.5` son las 14:30, `0` la medianoche, hasta `23.98…`. `time.hour: { gte: 18 }`: desde las seis de la tarde.                                                                                                                                                                                             |
| `time.watch`      | `watch`      | número o id       | La guardia del día, cuando el calendario tiene una división `watch`: de 1 al número de guardias con `every` (el de por defecto: seis de cuatro horas, la 1 de medianoche a las 4:00), o el id de su parte con guardias propias (`time.watch: middle`); no está en un hueco.                                                                       |
| `time.<división>` | `<división>` | id o número       | Con divisiones del día en el calendario: la parte en que está ahora cada una, por el id de la división (`time.meal: elevenses`; el número en una numerada, `time.bell: 3`); no está en un hueco. Su nombre corto solo cuando no es el de otro dato (una división `region` es solo `time.region`). Sistemas → **Calendario** → Divisiones del día. |
| `time.tags`       | —            | lista de palabras | Las etiquetas de cada parte en que está ahora (`time.tags: dark`); vacía sin divisiones.                                                                                                                                                                                                                                                          |
| `time.month`      | `month`      | id                | Con un calendario propio del sistema: el id del mes (Sistemas → **Calendario**: el id de cada mes).                                                                                                                                                                                                                                               |
| `time.monthDay`   | `monthDay`   | número            | Con un calendario propio del sistema: el día del mes, desde 1.                                                                                                                                                                                                                                                                                    |
| `time.year`       | `year`       | número            | Con un calendario propio del sistema: el año.                                                                                                                                                                                                                                                                                                     |
| `time.weekday`    | `weekday`    | id                | Con un calendario con días de la semana: el id del de hoy.                                                                                                                                                                                                                                                                                        |
| `time.moons.<id>` | `moons.<id>` | id                | Con lunas en el calendario: la fase de cada luna por el id de la luna: `new`, `waxing`, `full` o `waning` (`time.moons.pale: full`).                                                                                                                                                                                                              |
| `time.holidays`   | `holidays`   | lista de ids      | Con fiestas en el calendario: los ids de las de hoy (vacía casi todos los días).                                                                                                                                                                                                                                                                  |

## El día del sistema, `system.*`

Números de las reglas del propio sistema (Sistemas → **Reglas**), para compararse con ellos sin escribirlos dos veces: `time.hour: { gte: '{{system.part.night}}' }`.

| Nombre completo             | Corto         | Tipo   | Valores                                                                                                                                  |
| --------------------------- | ------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `system.hoursPerDay`        | `hoursPerDay` | número | Las horas en que sus formas de viajar hacen sus km al día (`8`): `trip.marched: { lt: '{{system.hoursPerDay}}' }` en su marcha.          |
| `system.<división>.<parte>` | —             | número | Cuándo empieza una parte del día del calendario, como hora (`system.meal.dinner`: `18`): `time.hour: { gte: '{{system.meal.dinner}}' }`. |

## El viaje, `trip.*`

En un viaje (Jugar en Mapa, Viajes), para sus comprobaciones y acciones, y en las tiradas a mano durante él.

| Nombre completo                               | Corto            | Tipo             | Valores, y de dónde salen                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------- | ---------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `trip.day`                                    | `tripDay`        | número           | El día de este viaje: 1 el día que empezó.                                                                                                                                                                                                                                                                                                                                                       |
| `trip.mode`                                   | `mode`           | id               | El id de la forma de viajar (`foot`, `horse`, `boat`…): las del sistema (Sistemas → **Reglas** → Formas de viajar); el selector del viaje enseña sus nombres.                                                                                                                                                                                                                                    |
| `trip.weather`                                | `weather`        | id               | El clima de hoy cuando una tabla o un modelo de clima lo ha fijado: los ids que declara el clima del sistema (Sistemas → **Reglas** → Clima, o los modelos de **Clima**). No está hasta entonces.                                                                                                                                                                                                |
| `trip.connections`                            | `connections`    | lista de ids     | Los tipos de conexión del tramo (caminos, senderos, ríos): `road`, `trail`, `river` (o los que declare el sistema), con los de las conexiones dibujadas en el mapa (las **Conexiones** de Mapa: un `bridge`, un `tunnel`…). Al entrar en un hex, el recién recorrido; si no, el de delante en la ruta (en un momento del día, al acampar, en una acción). Vacía fuera de ellos.                  |
| `trip.marched`                                | `marched`        | número           | Horas marchadas hoy (`2.5`).                                                                                                                                                                                                                                                                                                                                                                     |
| `trip.doneToday`                              | `doneToday`      | lista de ids     | Los ids de las acciones hechas hoy (`trip.doneToday: forage`): las acciones del sistema (Sistemas → **Reglas** → Acciones).                                                                                                                                                                                                                                                                      |
| `trip.routeLeft`                              | `routeLeft`      | número           | Hexes que faltan hasta el destino (0 sin ruta).                                                                                                                                                                                                                                                                                                                                                  |
| `trip.arrived`                                | `arrived`        | sí/no            | Si el grupo está en su destino.                                                                                                                                                                                                                                                                                                                                                                  |
| `trip.visits`                                 | `visits`         | número           | Veces que el grupo ha estado en este hex durante el viaje: `1` la primera vez.                                                                                                                                                                                                                                                                                                                   |
| `trip.moment`                                 | `moment`         | id               | Para las acciones y comprobaciones de un sistema: el momento que las trajo: `trip.place-enter`, `time.day-end`, una hora (`06:00`), una parte del día del calendario (`time.part.morning`), una acción (`actions.camp`) un reloj del mundo al llenarse, `world.clocks.<id>.full`, o un turno del mundo, `world.turn` (para una acción con `on:` o una comprobación con `at:` que nombra varios). |
| `trip.doing`                                  | `doing`          | id               | La acción en curso (`camp`; en `time.day-end`, aquella con la que acabó el día). No está si no hay ninguna.                                                                                                                                                                                                                                                                                      |
| `trip.below`, `trip.above`                    | `below`, `above` | lista de nombres | Lo que un efecto intentó llevar más allá de su `min` (`trip.below: party.values.food`) o su `max` hoy, por su nombre completo: las características del grupo, los valores y objetos de su hoja (`party.items.ration`), los valores de los personajes (`characters.kael.values.health`).                                                                                                          |
| `trip.places`                                 | —                | número           | Hexes en los que ha entrado el viaje.                                                                                                                                                                                                                                                                                                                                                            |
| `trip.km`                                     | —                | número           | Los km de esos pasos, cada uno a la escala del mapa (Ajustes del mapa), si no la del sistema (`travel.hexKm`).                                                                                                                                                                                                                                                                                   |
| `trip.hours`                                  | —                | número           | Horas de marcha desde que empezó el viaje.                                                                                                                                                                                                                                                                                                                                                       |
| `trip.checks`                                 | —                | número           | Comprobaciones que han salido durante el viaje.                                                                                                                                                                                                                                                                                                                                                  |
| `trip.taken.<acción>`                         | —                | número           | Veces que se ha hecho cada acción durante el viaje, por el jugador o por el propio sistema; están todas las que declara el sistema, a 0 hasta que se hacen (`trip.taken.camp: { gte: 7 }`).                                                                                                                                                                                                      |
| `trip.spent.<nombre>`, `trip.gained.<nombre>` | —                | número           | Cuánto han quitado y añadido las acciones, comprobaciones y tablas del sistema a cada valor y objeto del grupo (lo que cambias a mano no cuenta), por su nombre completo: `trip.spent.party.items.ration`, `trip.gained.party.values.food`; los suyos y los de sus personajes juntos, todos desde 0.                                                                                             |

La línea **Hasta ahora** del panel del viaje (ábrela para ver el resto) enseña estas cuentas tal como van.

**Los parámetros de una acción, `params.*`.** Las propias condiciones de una acción (`when` / `unless`), sus pasos y las condiciones de estos también leen los parámetros con los que se hizo: `params.until` es la opción elegida junto a su botón (o la que da el `with:` de un paso `do:`, o `travel.onward`), la de por defecto si nadie eligió (`travel.move: '{{params.until}}'`, un paso `when: { params.pace: quick }`). Solo ahí: las comprobaciones y las tablas no los ven. Mira [Acciones](../oracle/07-connecting.md#5-tu-propio-sistema-de-viaje).

## Alrededor del grupo, `from.*`, `around.*`

| Nombre                         | Tipo         | Valores                                                                                                                                                        |
| ------------------------------ | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `from.*`                       | grupo        | Al entrar en un hex, el que se deja, con los mismos nombres que `place.*`: `from.id`, `from.terrain`, `from.tags`, `from.region`, sus valores, `from.related`. |
| `around.terrain`               | lista de ids | Todos los terrenos de los hexes vecinos del grupo (`around.terrain: lake`: junto a un lago).                                                                   |
| `around.tags`, `around.region` | lista        | Todas las etiquetas, y todos los nombres de región, entre ellos.                                                                                               |
| `around.water`                 | sí/no        | Si alguno de ellos es agua.                                                                                                                                    |

En Viajes, los vecinos de un hex son el de antes y el de después en el camino.

## La conexión del paso, `connection.*`

La conexión del tramo en el que está el grupo (la que acaba de cruzar al entrar en un lugar, si no la de delante en la ruta), como la leen el **Abierto cuando** / **Cerrado cuando** de un terreno o de una conexión, el **Solo por** de una forma de viajar, las comprobaciones, las acciones y las tablas:

| Nombre               | Tipo            | Valores                                                                                                                                                                                   |
| -------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `connection.kind`    | id              | Su tipo: una conexión dibujada con las **Conexiones** de Mapa (`bridge`, `door`…), si no el camino o río que se sigue (`road`). Falta fuera de ellos.                                     |
| `connection.id`      | id              | El id de una conexión dibujada (falta en caminos y ríos).                                                                                                                                 |
| `connection.name`    | texto           | El nombre de una conexión dibujada, si tiene.                                                                                                                                             |
| `connection.tags`    | lista           | Las etiquetas de una conexión dibujada (`connection.tags: hidden`).                                                                                                                       |
| `connection.<clave>` | como se escribe | Los valores de una conexión dibujada (`connection.dc`), y lo que el viaje ha cambiado de ellos: `connection.state: open` cuando un efecto la abrió. El cambio del viaje gana al del mapa. |

En Viajes, la conexión al hex siguiente es la del tramo: su primer tipo, con un id propio (`leg-0`, `leg-1`…) para lo que cambia el viaje.

Un efecto `connection.<clave>` cambia la conexión del tramo en este viaje, nunca en el mapa: una palabra la fija (`connection.state: open`), un número le suma (`connection.uses: -1`; `'=3'` la fija). El paso de una acción la cambia al momento, así que sus pasos siguientes ya lo ven; el resultado de una tabla o comprobación también. El diario lo dice (`Puerta de roble: state open`).

También `party.items.tags`, cada etiqueta de cada objeto. |

## Los valores del día, `today.*`, `yesterday.*`

| Nombre              | Tipo                 | Valores, y de dónde salen                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `today.<valor>`     | sí/no, número, texto | Los valores del día que declara el sistema (Sistemas → **Reglas** → Valores del día: `today.lost`, que fija el `set` de una tabla, un paso `set:` de una acción o el resultado de una comprobación), y el clima que fijó antes hoy una tabla (`weather`); un modificador declarado igual (`today.fordModifier`). Se borran al acabar el día, a medianoche. Cada uno está también por su propio nombre: `lost`, `fordModifier`. El diario dice cuándo se fija cada uno. |
| `yesterday.<valor>` | como `today`         | Los del día anterior: `yesterday.lost` (el grupo lo acabó perdido; `false` si no), `yesterday.weather`… P. ej. reencontrar el camino con desventaja: `modeWhen: { roll-modes.disadvantage: { yesterday.lost: true } }`.                                                                                                                                                                                                                                                |

## Personajes

Cuando el sistema tiene una [hoja](07-kinds.md#hojas) y el grupo tiene personajes (la sección **Personajes** del viaje). Los ids son los de los personajes (cada ficha dice cómo se lee: `characters.kael.values.health`); los valores y estados, los que declara la hoja del sistema (Sistemas → **Hoja**).

| Nombre                                                                           | Tipo          | Valores                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `party.members`                                                                  | lista de ids  | Los ids de los personajes: `party.members: kael` se cumple mientras Kael viaje con el grupo.                                                                                                                                                                                              |
| `characters.<id>.values.<valor>` (también `characters.<id>.<valor>`)             | número        | Un valor de un personaje, dentro de los límites que le da la hoja.                                                                                                                                                                                                                        |
| `characters.<id>.conditions`                                                     | lista de ids  | Los estados que tiene ahora (`characters.kael.conditions: wounded`).                                                                                                                                                                                                                      |
| `characters.<id>.tags`, `characters.<id>.name`                                   | lista, texto  | Sus etiquetas y su nombre.                                                                                                                                                                                                                                                                |
| `characters.<id>.relations.<tipo>`, `characters.<id>.bonds.<tipo>`               | lista, número | Sus relaciones por tipo (`characters.mara.relations.home: region:Ashford Vale`: `region:<nombre>`, `hex:<id>`, `poi:<id>` o `character:<id>`) y el número que lleva cada una.                                                                                                             |
| `characters.<id>.items.<objeto>.count`, `characters.<id>.items.<objeto>.<campo>` | número        | Cuántos tiene de un objeto (todos, por el id del objeto: `characters.kael.items.torch.count: { gte: 1 }`) y los campos del primero tal como los declara la hoja (`….items.torch.uses`). Sin ese objeto: no hay nada, así que `{ exists: false }` se cumple.                               |
| `characters.<id>.items.tags`, `characters.<id>.items.<objeto>.tags`              | lista         | Todas las etiquetas de todos los objetos que lleva (`acting.items.tags: light`), y las de un objeto.                                                                                                                                                                                      |
| `characters.<id>.places.<lugar>.used`, `.room`, `.items`                         | número, lista | Cada lugar (los de la hoja, los propios y sus contenedores por clave): cuánto está ocupado (según **Lo que ocupa un lugar**), su sitio y los ids de los objetos que hay justo en él. Mira [Objetos](../systems/08-items.md).                                                              |
| `characters.<id>.carried.used`, `.room`                                          | número        | Todo lo que lleva (cada objeto, también lo de dentro de contenedores y lo que no está en ningún lugar, según **Lo que ocupa un lugar**), y el **Sitio en total** de la hoja (sin él: no hay `.room`). Mira [Límites a lo que se lleva](../systems/08-items.md#limites-a-lo-que-se-lleva). |
| `roles.<rol>.*`                                                                  | grupo         | Quien tiene uno de los roles de viaje del sistema (Sistemas → **Comprobaciones** → Roles de viaje), con los mismos nombres: `roles.guide.values.pathfinding: { gte: 2 }`. Si nadie lo tiene, no hay `roles.<rol>`.                                                                        |
| `acting.*`                                                                       | grupo         | El personaje que actúa ahora (elegido en el viaje), con los mismos nombres: `acting.values.survival: { gte: 2 }`. Si no actúa nadie, no hay `acting`, y una condición sobre él no se cumple.                                                                                              |
| `place.related`, `place.relations.<tipo>`, `from.related`                        | lista de ids  | Quién está unido al hex (él, su región o un lugar en él) y por qué tipo de relación; `from.related` para el hex que se deja.                                                                                                                                                              |

Los efectos llegan a ellos con los mismos nombres ([Sintaxis](09-syntax.md#cambiar-el-grupo-effects)): `party.members.values.health: -1` (todos los personajes), `characters.kael.conditions.wounded: true` (uno), `acting.values.health: 1` (el que actúa; si no actúa nadie, no cambia nada, y el diario lo dice), `roles.lookout.values.health: -1` (quien tenga un rol), `acting.items.torch: -1` (un objeto menos; `+1` da uno, de los catálogos del sistema si no tiene ninguno), `party.members.items.torch.uses: -1` (un campo de la primera antorcha de cada uno). Un grupo sin personajes los ignora: el mismo sistema se juega con personajes o sin ellos.

Un valor que **sale de otros** (`from:` en la hoja) y un estado que **se cumple por sí solo** (`when:`) se leen como cualquier otro, pero ningún efecto los cambia: el diario dice _«Kael: Heridas» se mantiene por sí solo…_ y no cambia nada. Dentro de su propia hoja (un `from`, un límite, el `when` de un estado), un personaje se lee a sí mismo como `self.*`: `self.values.health`, `self.conditions`, `self.tags`; el `when` de un estado lee también el mundo, con los nombres de esta página ([Hojas](07-kinds.md#hojas)).

Las características del grupo que un sistema saca de sus personajes (`from` en sus bindings) se leen como cualquier otra (`party.stats.navigation`), y los objetos que llevan como los del grupo juntos: `party.items.ration.count`.

## Los presentes, `present.*`

Cuando el sistema tiene un [bestiario](07-kinds.md#bestiarios) y un resultado ha hecho copias de sus plantillas (`present.wolf: 3`): las copias que están donde el grupo. Cada copia es también un personaje, que se lee por su id como los del grupo (`characters.wolf-2.values.health`), con los valores y estados de su propia hoja.

| Nombre                                                 | Tipo                 | Valores                                                                                                                |
| ------------------------------------------------------ | -------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `present.ids`                                          | lista de ids         | Las copias que están aquí: `present.ids: wolf-2` se cumple mientras ese lobo esté aquí.                                |
| `present.count`                                        | número               | Cuántas hay aquí, de todas las plantillas.                                                                             |
| `present.tags`                                         | lista                | Todas las etiquetas de los que están aquí: `present.tags: outlaw`.                                                     |
| `present.<plantilla>.count`, `present.<plantilla>.ids` | número, lista de ids | Cuántas copias de una plantilla hay aquí, y cuáles; están todas las plantillas del sistema, a 0 cuando no hay ninguna. |
| `characters.<id>.*`                                    | grupo                | Una copia que está aquí, con los nombres de [Personajes](#personajes).                                                 |

Los efectos llegan a ellas con los mismos nombres ([Sintaxis](09-syntax.md#cambiar-el-grupo-effects)): `present.wolf: 2` (dos lobos más), `present.wolf.values.health: -1` (cada lobo de aquí), `present.all.conditions.routed: true` (todos los de aquí), `characters.wolf-2.values.health: -1` (uno). Las copias que el grupo dejó atrás no están aquí, y las de una plantilla con `behind: leave` desaparecen; una copia con un estado que `leaves` desaparece al momento.

## Descubrir el mapa

- La tabla de **terreno** ve el hex donde está el grupo (su terreno, etiquetas, valores y región), más `place.id` (el hex que se decide), `from` (desde el que se ve: `from.id`, `from.terrain`…) y la tierra alrededor del hex que se decide: `around` cuenta los terrenos de sus vecinos conocidos (`around.lake: 2`), `aroundCount` cuántos se conocen, `common` el terreno más frecuente (en un empate gana el del hex desde el que se ve) y `commonCount` cuántos lo tienen.
- La tabla de **contenido** ve el hex al que se entra (`place.terrain`, `place.tags`… y `terrain` en corto).
- Las dos ven las características del grupo, `party` y los valores del día.

## Qué valor gana

Cuando dos fuentes dan el mismo nombre, gana la posterior:

1. **Comprobaciones:** características del grupo por nombre → valores del día → lo del mapa y del viaje → `party` → contexto del binding. Así una característica o un valor del día llamado `terrain` o `weather` no puede tapar el de verdad; `party.stats.terrain` sigue llegando a ella. **Los nombres completos nunca coinciden**: `place.terrain`, `trip.weather`, `party.stats.weather` son siempre lo que dicen; solo se comparten los cortos. Nombres reservados que una característica no debería usar: los nombres cortos de las tablas de arriba, y los grupos `hex`, `time`, `system`, `trip`, `world`, `party`, `today`, `yesterday`, `from`, `around`, `characters`, `acting`, `roles`, `factions`, `faction`, `icon`, `token`, `name`; en una tabla con tirada, `roll` y `result`.
2. **Tiradas a mano** (panel Oráculo): durante un viaje, el mismo orden que las comprobaciones; después el token → lo que escribes en el **Contexto** del panel de tirada. Un `token.fare` escrito cambia solo ese valor del token.
3. **Dentro de una tabla:** los valores que fija una entrada (`set`) llegan a la tabla que tira a continuación; los campos de un generador ven los anteriores, y el `context` de un campo añade valores solo para ese campo.

Algunas coincidencias, y lo que pasa:

- **Un valor de región y uno de hex** con el mismo nombre (`danger: 2` en el Bosque Gris, `danger: 5` en uno de sus hexes): allí gana el del hex, en el resto el de la región. Así hacen las Marcas Grises que el bosque sea más peligroso hacia su corazón.
- **Una característica que se llama como un dato** (una característica `weather`, o `terrain`): `{{trip.weather}}` y `when: { trip.weather: storm }` leen el clima del día, nunca la característica; esta sigue siendo `party.stats.weather`. Mejor no usar esos nombres (la lista de arriba).
- **Un valor de un icono o token llamado `terrain`**: se lee como `icon.terrain` / `token.terrain`, dentro de su propio nombre, así que no tapa el terreno del hex.
- **Un valor que fija una entrada con el nombre de una característica** (`set: { morale: 1 }` con una característica `morale`): el texto del resultado y las tablas que tira leen `{{morale}}` como 1, pero no cambia la característica ni se mantiene el resto del día (solo lo hacen `weather` y los valores declarados). Para cambiarla, usa `effects: { party.stats.morale: 1 }`.
- **El contexto de un binding** (`context: { timeOfDay: night }`) gana a todo para su comprobación: así la misma tabla responde a los encuentros de día y de noche.

## Tipos de valor, en detalle

- Los valores escritos en el mapa (de un hex, una región, un icono, un token) se leen como en YAML: `3`, `-1`, `2.5` son **números** (se suman en los dados y se comparan con `gt` / `gte` / `lt` / `lte`), `true` y `false` son **sí/no**, lo demás es **texto** (`Brenna`, `3 platas`).
- En los dados, un valor que falta cuenta como **0**: `1d6 + {{place.danger}}` funciona donde no hay peligro.
- En las condiciones, un valor que falta no cumple, salvo con `exists: false` o `not`; una comparación con un valor que no es un número nunca se cumple. Todos los operadores, con ejemplos: [Condiciones](08-conditions.md).
- Una **lista** cumple cuando tiene el valor que se pide (`place.tags: ford`), o cualquiera de varios (`place.tags: [ford, bridge]`).
- Los nombres con puntos leen dentro de un grupo: `token.fare`, `icon.guards`, `npc.role` (un campo de un generador).

Las Marcas Grises usan todos ellos; [Las Marcas Grises](../packs/02-grey-marches.md) dice dónde.
