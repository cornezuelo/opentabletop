# Atajos de teclado

| Tecla                                                                        | Acción                                                |
| ---------------------------------------------------------------------------- | ----------------------------------------------------- |
| <kbd>V</kbd>                                                                 | Seleccionar                                           |
| <kbd>B</kbd> / <kbd>G</kbd> / <kbd>E</kbd>                                   | Terreno: pincel / rellenar / borrar                   |
| <kbd>[</kbd> <kbd>]</kbd>                                                    | Pincel más pequeño / más grande                       |
| <kbd>N</kbd>                                                                 | Regiones                                              |
| <kbd>R</kbd>                                                                 | Caminos y ríos                                        |
| <kbd>I</kbd>                                                                 | Iconos                                                |
| <kbd>T</kbd>                                                                 | Texto                                                 |
| <kbd>K</kbd>                                                                 | Tokens                                                |
| <kbd>P</kbd>                                                                 | Jugar                                                 |
| <kbd>O</kbd>                                                                 | Panel del Oráculo                                     |
| <kbd>F</kbd>                                                                 | Encuadrar el mapa                                     |
| <kbd>Espacio</kbd> + arrastrar, botón central                                | Desplazar                                             |
| Rueda                                                                        | Zoom                                                  |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Mayús</kbd>+<kbd>Z</kbd> | Deshacer / rehacer                                    |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>O</kbd>                  | Guardar / abrir un fichero                            |
| <kbd>Supr</kbd>                                                              | Quitar el icono, rótulo o token seleccionado          |
| <kbd>Esc</kbd>                                                               | Deseleccionar, cancelar una línea                     |
| <kbd>Intro</kbd> / <kbd>Retroceso</kbd>                                      | Terminar una línea / quitar su último punto           |
| <kbd>Ctrl</kbd>+clic                                                         | Coger el terreno, la región o el icono bajo el cursor |
