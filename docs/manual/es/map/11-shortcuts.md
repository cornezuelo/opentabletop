# Atajos de teclado

No necesitas tener esta página abierta para encontrarlos: Mapa muestra sus teclas donde las usas.

- Pulsa <kbd>?</kbd>, o el teclado de la barra de arriba, para ver **Atajos de teclado**: todas las teclas de Mapa según para qué sirven, y las que comparten todas las aplicaciones.
- Pasa el ratón por un botón para ver su tecla junto a su nombre (_Terreno_ <kbd>B</kbd>, _Deshacer_ <kbd>Ctrl</kbd>+<kbd>Z</kbd>).
- Una herramienta con teclas propias las lista al pie de su panel, en **Teclas de …** (_Teclas de Terreno_): un clic las despliega, y Mapa recuerda si las dejas abiertas.

## Herramientas

| Tecla                                      | Herramienta                        |
| ------------------------------------------ | ---------------------------------- |
| <kbd>V</kbd>                               | Seleccionar                        |
| <kbd>B</kbd> / <kbd>G</kbd> / <kbd>E</kbd> | Terreno: pincel / relleno / borrar |
| <kbd>N</kbd>                               | Regiones                           |
| <kbd>L</kbd>                               | Facciones                          |
| <kbd>R</kbd>                               | Caminos y ríos                     |
| <kbd>W</kbd>                               | Muros                              |
| <kbd>C</kbd>                               | Conexiones                         |
| <kbd>I</kbd>                               | Iconos                             |
| <kbd>T</kbd>                               | Texto                              |
| <kbd>K</kbd>                               | Tokens                             |

Al jugar, solo <kbd>V</kbd> cambia de herramienta: las herramientas que editan el mapa no tienen teclas, así que un despiste no convierte un clic en un trazo.

## La vista

| Tecla                                                          | Qué hace                                              |
| -------------------------------------------------------------- | ----------------------------------------------------- |
| <kbd>P</kbd>                                                   | Editar o Jugar (el interruptor de arriba)             |
| <kbd>Espacio</kbd>+arrastrar, o arrastrar con el botón central | Mover el mapa                                         |
| Rueda                                                          | Zoom                                                  |
| <kbd>F</kbd>                                                   | Encuadrar el mapa                                     |
| <kbd>O</kbd>                                                   | El panel de Oráculo                                   |
| <kbd>?</kbd>                                                   | Atajos de teclado (los tienen todas las aplicaciones) |
| <kbd>F1</kbd>, en un campo                                     | Su explicación, en la columna de ayuda                |

## Edición

| Tecla                                                                        | Qué hace                                                             |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>                                                 | Deshacer                                                             |
| <kbd>Ctrl</kbd>+<kbd>Mayús</kbd>+<kbd>Z</kbd> o <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Rehacer                                                              |
| <kbd>Ctrl</kbd>+<kbd>S</kbd>                                                 | Guardar                                                              |
| <kbd>Ctrl</kbd>+<kbd>O</kbd>                                                 | Abrir un fichero de mapa                                             |
| <kbd>Supr</kbd> o <kbd>Retroceso</kbd>                                       | Quitar el icono, rótulo, token o conexión seleccionado               |
| Clic derecho                                                                 | Quitar lo que hay bajo el cursor (un icono, rótulo, token, conexión) |
| <kbd>Esc</kbd>                                                               | Soltar lo seleccionado                                               |

## Terreno

| Tecla                       | Qué hace                                   |
| --------------------------- | ------------------------------------------ |
| <kbd>[</kbd> / <kbd>]</kbd> | Pincel más pequeño / más grande            |
| <kbd>Mayús</kbd>+arrastrar  | Pintar un rectángulo (una sala de una vez) |
| <kbd>Ctrl</kbd>+clic        | Tomar el terreno bajo el cursor            |
| Clic derecho                | Borrar                                     |

Las regiones toman <kbd>Mayús</kbd>+arrastrar y <kbd>Ctrl</kbd>+clic igual.

**Dibujar con el teclado** ([Terreno](02-terrain.md#dibujar-con-el-teclado)): una flecha alarga un pasillo desde la casilla seleccionada, <kbd>Mayús</kbd>+flecha solo se mueve, <kbd>R</kbd> pinta una sala alrededor de la casilla, <kbd>D</kbd> una puerta hacia la casilla de la que vino, <kbd>Esc</kbd> suelta (y <kbd>R</kbd> vuelve a ser Caminos y ríos).

## Caminos y ríos

| Tecla                                 | Qué hace                                    |
| ------------------------------------- | ------------------------------------------- |
| <kbd>Intro</kbd> o clic derecho       | Terminar la línea                           |
| <kbd>Retroceso</kbd>                  | Quitar su último punto                      |
| <kbd>Esc</kbd>                        | Cancelar la línea                           |
| <kbd>Mayús</kbd>+clic                 | Un punto donde haces clic, fuera del centro |
| <kbd>Ctrl</kbd>+<kbd>Mayús</kbd>+clic | Un punto donde haces clic, sin ajustar      |

## Jugar

| Tecla                                                          | Qué hace                                                          |
| -------------------------------------------------------------- | ----------------------------------------------------------------- |
| Flechas, o <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | En un viaje: el grupo da un paso hacia allí ([Jugar](08-play.md)) |
